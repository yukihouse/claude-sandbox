# ぺんぎん族（ぺんぎんぞく）〜南極進化記〜

南極を舞台にした、ターン制の「群れ育成サバイバル」ゲームです。ブラウザで遊べます。
昔のガラケーで遊ばれていた、動物の群れを世代交代させながら進化させる育成シミュレーションの遊び方を下敷きに、
舞台を南極大陸、主人公をペンギンの群れにして、一から作りました（キャラクター・絵・文章はすべてオリジナルです）。

画面はガラケー風です。↑↓と決定だけで遊べ、数字キー 1〜9 で項目を直接えらぶこともできます。

TypeScript と Vite で書かれています。ビルドすると JS と CSS を埋め込んだ HTML ファイル 1 つ
（`dist/index.html`）ができ、ブラウザで開けばそのまま遊べます。進行は自動でブラウザに保存されます（localStorage）。

## 遊び方

1 ターン ＝ 1 季節（春・夏・秋・冬）。季節ごとに、おとなのペンギン 1 羽ずつに「しごと」を決めて、季節をすすめます。

| しごと | 内容 |
| --- | --- |
| オキアミとり | 安定して食料がとれる。土地のオキアミには限りがある |
| 漁 | 魚がとれるが、素手だとけがをしやすい。素手の漁を何度かすると「骨のモリ」を思いつく |
| モリづくり | モリを作る（「骨のモリ」を発明したあと）。モリを持って漁に出ると、魚がたくさんとれる。モリは1回の漁で1本使う |
| ひなたぼっこ | 休んでいるオスとメスがつがいになり、つがいがそろって休むとひなが生まれる。発明のひらめきもたまる |
| いのり | 族長だけ。けがや病気が治る、能力が上がる……ときどき族長の寿命がちぢむ |

- **族長**と同じしごとをするペンギンは、はかどります（1.3倍。「ことば」を発明すると1.5倍）。
- **食料**は1羽1季節に1つ。3季節続けて足りないとうえ死にします。食料は季節ごとに1割くさります。
- **ひっこし**: 土地のえさは食べると減り、少しずつしか戻りません。となりの土地へ移れます（1羽につき食料1。その季節はしごとなし）。
- **寒さ**: 冬や寒い土地では、寒さに弱いペンギンがかぜをひきます。「羽づくろい」で寒さに強くなります。
- **危険**: ブリザード、シャチ（その土地の魚を食べつくし、しばらく海が危険に）、ヒョウアザラシ、氷山の崩落、流行り病、大寒波、トウゾクカモメ（ひなをねらう。休んでいるおとなが2羽いれば守れる）、ほかの群れとのなわばり争い（「ことば」があれば話し合いで仲間や食料をもらえることも）。
- **進化**: ひなは両親の能力の平均を受けつぎ、少しずつ変化します。「ことば」があると、ひなはかしこく生まれます。
- **発明**（5つ）: 骨のモリ、ことば、羽づくろい、モリみがき、よびうた。ひなたぼっこでたまる「ひらめき」で、ランダムに身につけます。

**クリア**: 発明を5つすべて身につけたうえで、ちえ80以上のひなが生まれること。
**ゲームオーバー**: 群れの全滅。

舞台の7つの土地（南極半島、ウェッデル海、リュツォ・ホルム湾、プリッツ湾、アデリーランド、ロス海、アムンゼン海）は、
南極大陸の海岸ぞいにある実在の地名です。

## 開発

Node.js 22 以上が必要です。

```bash
npm ci
npm run dev        # 開発サーバー
npm run build      # 型チェックして dist/index.html を作る
npm run coverage   # テストとカバレッジ
```

| ファイル | 中身 |
| --- | --- |
| `src/game/rules.ts` | ルール全部（しごと、イベント、食事、寒さ、寿命、発明、勝敗）。DOM に依存しない |
| `src/game/rng.ts` | 乱数（シード付き。セーブに入るので、続きからでも同じ乱数列） |
| `src/data/` | 土地・発明・名前のデータ |
| `src/save.ts` | localStorage へのセーブとロード（壊れたデータは読みこまない） |
| `src/render/scene.ts` | 上の画面のドット絵（Canvas） |
| `src/main.ts` | メニュー画面、キー入力、画面の切り替え |

`src/game/`、`src/data/`、`src/save.ts` はテストで 100% カバーします。Canvas の描画と DOM の配線は、
ビルドしたゲームをブラウザで動かして確認します。

`tests/balance.test.ts` は、単純な作戦で40回遊ばせて、勝てることも負けることもあり、クリアまでの長さが
ほどよいことを確かめます。数値を変えたときの安全網です。
