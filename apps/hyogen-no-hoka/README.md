# 氷原の烽火（ひょうげんのほうか）

南極を舞台にした、ブラウザで遊べる陣取り型のリアルタイムストラテジーゲームです。
黒氷社に占拠された観測基地を、オーロラ隊の隊長・凪となってひとつずつ取り戻します。
登場する人物・団体はすべて架空のものです。

TypeScript と Vite で書かれています。ビルドすると JS と CSS を埋め込んだ HTML ファイル 1 つ
（`dist/index.html`）ができ、ブラウザで開けばそのまま遊べます。

## 開発

Node.js 22 以上が必要です。

```bash
npm ci
npm run dev        # 開発サーバー（保存すると即反映）
npm run build      # 型チェックして dist/index.html を作る
npm run coverage   # テストとカバレッジ
```

| ディレクトリ | 中身 |
| --- | --- |
| `src/game/` | ルール・AI・プレイヤー操作（DOM に依存しない純粋なロジック） |
| `src/data/` | 章と登場人物のデータ |
| `src/render/` | Canvas への描画と座標変換 |
| `src/ui/` | 下のバーと会話シーン |
| `src/main.ts` | 起動、入力、画面の切り替え、ゲームループ |

`src/game/`、`src/data/`、`src/save.ts`、`src/render/view.ts` はテストで 100% カバーします。
Canvas の描画と DOM の配線は、ビルドしたゲームをブラウザで動かして確認します。

## 名前の由来

「烽火」は杜甫の『春望』の一節「烽火 三月に連なり」（「国破れて山河在り」と同じ詩）から取りました。
南極の氷原に上がる、救援ののろしをイメージしています。

## 遊び方

内政はありません。操作は次の3つだけです。

1. 自軍の基地（青）をタップする
2. 下のバーで、送る隊員の割合（10〜100%）を決める
3. 向かう基地をタップすると、隊員が出動する

基地から基地へドラッグしても出動できます。

- 基地の隊員は時間とともに増えます。観測小屋 → 基地 → 本部の順に、増える速さと上限が大きくなります
- 無人基地（灰色）は隊員が増えません。早めに押さえると有利です
- 相手の隊と途中でぶつかると、少ないほうの人数ぶん互いに減ります
- クレバス帯の中では移動速度が半分になります

### アイテム

| アイテム | 効果 |
| --- | --- |
| 補給便 | 自軍の基地に隊員 +15 |
| 雪上車 | 自軍の移動が12秒間 2倍速 |
| 防寒壁 | 自軍の基地の守りが20秒間 2倍 |

補給便と防寒壁は、基地を選んだ状態で押すとその基地にすぐ使えます。

## 章立て

全5章で、各章の前後にキャラクターの会話シーンが入ります。

| 章 | 名前 | 特徴 |
| --- | --- | --- |
| 第一章 | 白い夜明け | 操作に慣れるための章 |
| 第二章 | 氷河の基地 | クレバス帯が移動を遅らせる |
| 第三章 | 三つ巴の氷原 | 黒氷社と漂流団との三つ巴 |
| 第四章 | 大クレバスを越えて | 幅の広いクレバスを挟んだ攻防 |
| 終章 | 南極点 | 隊員の集まりが速い本部を落とす |

進み具合はブラウザの localStorage に保存されます。
