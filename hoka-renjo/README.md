# 烽火連城（ほうかれんじょう）

ブラウザで遊べる、陣取り型のリアルタイムストラテジーゲームです。
都を落とされた翠嶺国の若き将・蒼真となり、城をひとつずつ取り戻していきます。

ビルド不要の単一 HTML ファイルです。`index.html` をブラウザで開けば遊べます。

## 遊び方

1. 自軍の城（藍色）をタップする
2. 下のスライダーで、送る兵の割合（10〜100%）を決める
3. 攻める城をタップすると、兵が出陣する

城から城へドラッグしても出陣できます。

- 城の兵は時間とともに増えます。城が大きいほど速く増え、上限も高くなります
- 中立（灰色）の城は兵が増えません。早めに押さえると有利です
- 敵の部隊と道中でぶつかると、少ないほうの兵数ぶん互いに減ります
- 川の中では進軍速度が半分になります

### アイテム

| 札 | 効果 |
| --- | --- |
| 援軍 | 自軍の城に兵 +15 |
| 疾風 | 自軍の進軍が12秒間 2倍速 |
| 堅城 | 自軍の城の守りが20秒間 2倍 |

援軍と堅城は、城を選んだ状態で押すとその城にすぐ使えます。

## 章立て

全5章で、各章の前後にキャラクターの会話シーンが入ります。

| 章 | 名前 | 特徴 |
| --- | --- | --- |
| 第一章 | 落城の夜 | 操作に慣れるための章 |
| 第二章 | 渓谷の砦 | 川が進軍を遅らせる |
| 第三章 | 山賊の山 | 黒鉄帝国と赤狼党との三つ巴 |
| 第四章 | 大河を越えて | 幅の広い大河を挟んだ攻防 |
| 終章 | 王都奪還 | 兵の伸びが速い本城を落とす |

進み具合はブラウザの localStorage に保存されます。
